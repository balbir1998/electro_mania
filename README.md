# 🛒 Electro Mania

🚀 **Electro Mania** is a frontend eCommerce web application built using **HTML, CSS, and Vanilla JavaScript**.  
It focuses on core frontend concepts like **DOM manipulation**, **state management**, and **clean modular code**, with cart and wishlist data stored using **LocalStorage**.

---

## 🌐 Live Demo
🔗 https://electro-mania-store.netlify.app/

---

## ✨ Features
✅ Dynamic product rendering  
✅ Category-based product filtering  
✅ Add to Cart functionality  
✅ Wishlist feature  
✅ Cart & wishlist persistence using LocalStorage  
✅ Modular and clean JavaScript structure  
✅ Responsive user interface  

---

## 🛠️ Tech Stack
🧱 HTML5  
🎨 CSS3  
⚙️ JavaScript (ES6+)  
💾 Browser LocalStorage  
🚀 Netlify (Deployment)

---

## 📂 Project Structure
📁 /data — product data files  
📁 /js — main JavaScript logic and functionality  
📁 /styles — CSS files for styling  
📁 /assets — images and static resources  
📄 index.html — main HTML file 

---

## 🎯 Purpose
🎓 Built to strengthen frontend fundamentals and understand real-world eCommerce logic using **vanilla JavaScript**, without relying on frameworks or libraries.
